Daily Him

把每天的陪伴，放在主屏幕上。

用手机扫码打开

idol-chat.onrender.com/shell/install.html

扫码后会打开本站安装页，再按手机类型安装。

安卓

使用 Chrome 打开本页，可添加到主屏幕；也可以下载安装包。

若未弹出安装提示，请在 Chrome 菜单中选择「安装应用」或「添加到主屏幕」。

下载安卓安装包

正在检查安装包。当前可使用上方「添加到主屏幕」。

下载后打开 APK，按系统提示允许此浏览器安装应用，再点「安装」。需要支持 Trusted Web Activity 的浏览器（推荐 Chrome）和网络连接。

iPhone / iPad

请务必用 Safari 打开本页。

  1. 点 Safari 的「分享」按钮
  2. 选择「添加到主屏幕」
  3. 点「添加」，即可从主屏幕打开 Daily Him

iOS 不提供 IPA 一键下载，也无需前往 App Store。如果正在其他应用的内置浏览器中，请复制本页链接到 Safari。
