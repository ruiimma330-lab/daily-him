Daily Him

把每天的陪伴，放在主屏幕上。

用手机扫码打开

dailyhim.cn/shell/install.html

扫码后会打开本站安装页，再按手机类型安装。

安卓

请使用 Chrome 打开本页：

  1. 点 Chrome 右上角菜单
  2. 选择「安装应用」或「添加到主屏幕」
  3. 按提示确认安装

若未弹出安装提示，请在 Chrome 菜单中选择「安装应用」或「添加到主屏幕」。

下载安卓安装包
