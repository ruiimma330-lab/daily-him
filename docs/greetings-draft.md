# 预存问候语文案（10 × 3，待确认）

> 数据文件：`config/greetings.json`（唯一生效来源）
> 时区：Asia/Shanghai · morning 05:00–10:59 / afternoon 11:00–17:59 / evening 18:00–04:59
> 状态：**草稿，等 mma 确认用词**。改文件即可，不需要改代码或语音包。
> 本文件不含任何音频。以后补音频时：把 mp3 放进 `characters/<id>/greetings/`，并在
> `config/greetings.json` 对应句子加 `"audio": "文件名.mp3"`。预存音频**不扣星光**。

## 规则

- `slots`：还不知道怎么称呼时说的话；`withName`：已知称呼时说的话，必须带 `{callName}`。
- 每个时段各一句；想轮换可以在同一时段写多句，按天轮换。
- `askName`：还没定称呼时的开场（问怎么称呼），同样不经过 LLM。
- 所有句子都是一句话的气口，适合 TTS（≤ 40 字），不出现 AI / 模型 / 系统字样。
